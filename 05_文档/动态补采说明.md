# 动态补采说明（2026-11-17）

## 1. 先说清楚：组员不用做什么

楼梯判断的规则已经写进程序（演示 App 0.4 和 Python 脚本），手机会自动算。**采集时不用数转了几圈，也不用特意转身**，按平时的样子走楼梯、坐电梯就行。陀螺仪数据采集 App 一直在自动记录。

组员要做的只有一件事：按下面的步骤用**采集 App 1.1** 录几条新的动态数据。

## 2. 程序是怎么判断的（了解即可）

T8 的楼梯是折返式的：每上下一层，都要在中间平台掉头一次，身体转约 180°。走廊基本是直的。

1. 加速度计先找出"人在走路"的时间段。
2. 陀螺仪测出这段时间里身体绕竖直方向转了多少度。
3. 这段行走里有一次转身超过 90°，而且合计转了 150° 以上，就判为走了一层楼梯；否则当作平地行走。
4. 从上往下看，逆时针转是上楼，顺时针是下楼。T8 中间和东侧两个楼梯都是这样。
5. 电梯不靠转身，靠加速度计测出电梯起动和停下，再算出移动了几层。

旧规则用"走路时上下晃动的幅度"判断上楼还是下楼。换一个人走路的幅度就不一样，所以换成了陀螺仪。

## 4. 每条怎么录

**楼梯 / 电梯**（模式选"跨层（楼梯/电梯）"）

1. 填好：楼层 = 起点层，目标楼层 = 终点层，数据集 = **Test**，备注 = 上表的编号（例如 `T8-ST01-TS02`）。
2. **方式一定要选对**：走楼梯选"楼梯"，坐电梯选"电梯"。上次 11-16 那批全部选成了楼梯。
3. 站在楼梯口或电梯口，点 **开始采集**，原地站 10 秒。
4. 点 **开始移动**，然后正常走楼梯或进电梯。
5. 走楼梯时，每到一层楼的楼层标识处点一次 **经过一层**（可选）。
6. 到达目标层，点 **到达目标层**。
7. **原地站满 20 秒再点停止**。上次有一条到达后只站了 10 秒，App 还没来得及确认就停了。

**走廊行走**（模式选"行走"）：在路线起点点开始，正常走到另一头，点停止。

**手机拿法**：像看屏幕那样平拿在手里，全程不要放进口袋，也不要换手。电梯起动时尽量别晃手机，晃了会漏检。

**录坏了**：不要删。在备注里写明原因，再录一条，编号后面加 `-R2`。
