# BNBU-FloorSense (COMP4213)

Code and documents only. Raw Wi-Fi data and model files contain BSSIDs and are kept inside the team, not in this public repo.

| Folder | Content |
|---|---|
| `FloorSenseCollector_data/app` | Data collection app 1.1 (`edu.bnbu.floorsense.collector`) |
| `FloorSenseCollector_data/floorsense` | Demo prediction app (`edu.bnbu.floorsense.app`) |
| `floorsense_c` | Role C: static model pipeline and report (no data, no model files) |
| `validation_d2` | D2 validation: static variants, dynamic detection and fusion prototype |
| `legacy/FloorSenseCollector_v1.0` | Old collector 1.0, backup only |

Not included (get from the team drive): `floorsense/src/main/assets/knn_reference.json`, `floorsense/src/test/resources/fixtures.json`, `floorsense_c/data`, `floorsense_c/results/models`, all session folders.
