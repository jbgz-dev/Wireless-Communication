# T8 D3 完整静态测试（C 部分）

11 月 16 日的两份原始归档覆盖修订版 `D3_静动态Test规划(3).xlsx` 的全部 **70 个静态 Test 点**，其中 2–4F 有 **52 个**。按冻结版 V1 的 30 秒实时回放规则，基础三层楼层正确 **51/52（98.08%）**，五层楼层正确 **69/70（98.57%）**，70 点均有有效更新。课程的三层至少 50 个独立测试位置及 90% 楼层正确率两个量化要求已达到。现场实际站位需由采集组保留记录，供最终报告确认物理位置独立性。

## 评分与数据核对

- 使用冻结版 V1 及原特征配置，模型由 D1 Train 训练。每点独立冷启动，取前 30 秒内最后一次有效新估计，维持至少 15 个已知 AP 与 0.50 楼层投票分数的门限。新版工作簿保留 A–H 锚区，按冻结点位表使用 A/B→West、C/D/E→Middle、F/G/H→East。
- 静态归档提供 2–4F 52 条完整记录和 5–6F 18 条完整记录，录制 **33.97–51.36 秒**。6F-A 使用完整重录，同点未完成记录保留在审计表。混合归档还含 12 条跨层 Run，静态 C 评分只使用静态记录。
- 未发现与 D1 Train、D2 静态 Validation 重叠的点号、Session ID 或完全相同的清洗后 Wi‑Fi 指纹。新版工作簿列出的点位替换了原 74 点的覆盖口径，2F 的 D-TS03、D-TS04 和 5F 的 C-TS02、F-TS02 已从规划中删除。
- 本次静态测试均为 N 朝向，2–4F 使用 `24053PY09C`，5–6F 使用 vivo `V2068A`。D1 与 D2 各楼均记录了 N/E/S/W，日期也与本批 D3 分开。这批 D3 的设备与楼层分组绑定，暂无同点同条件的设备对照。
- 5F-A 的采集标签由 4F 改为 5F，按最终导出标签评分。剔除此点后为 **68/69（98.55%）**，基础三层结果相同。2F-E 及其余改过点号的记录按最终导出标签和修订规划对齐，变更见 [Session 审计表](session_audit.csv)。
