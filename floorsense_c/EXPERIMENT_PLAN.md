# C 岗位 Wi-Fi 基线实验

用户授权：按已有 C 岗位要求运行机器学习模型并验证准确度。

1. 核对 static_train 的 50 点、200 Session、楼层与规划 Zone；原始数据保持不变。
2. 以单次 Wi-Fi 扫描为输入，仅 BSSID/RSSI 为特征。检查空扫描、非法 RSSI、缓存标记、重复指纹、AP 缺失。主实验在每个 Point ID 内去除完全相同的特征指纹；跨点位同指纹如存在，合并成不可拆分评估组。
3. 固定超参数：KNN k=5 距离加权、欧氏距离；Random Forest 300 棵树。训练折独立建立 BSSID 词表，缺失 AP=-100 dBm，输入裁剪至[-100,-20]。不把点位、朝向、时间、SSID或传感器作为特征。
4. 按 Point ID 分组、按楼层分层的5折交叉验证，seed=42主结果，另43–46检验划分敏感性。所有朝向留在同一折。报告扫描准确率、macro F1、点位等权准确率、楼层与Zone同时正确率、混淆矩阵、错误点位。固定方案，不用评估折调参。
5. 比较未去重数据的同样分组结果（仅诊断）；导出全训练数据重拟合的基线模型、可复现代码和中文报告。明确内部交叉验证不代表跨时间/设备或独立测试集性能。

核验重点：训练和验证组交集为空、跨折相同指纹为零、词表不含验证独有AP、标签与规划一致、每个样本恰有一个主折预测、指标可由预测表重新计算、模型重载可推理。
